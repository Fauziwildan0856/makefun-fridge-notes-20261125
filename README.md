Entry for the make.fun bounty
[Notes From a Passive-Aggressive Fridge](https://make.fun/c/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7):
one funny passive-aggressive note a smart fridge leaves for its owner —
dry, petty and specific, with a sting the reader does not see coming.

## The entry

> Your yogurt expired Tuesday. I watched you sniff it, eat it anyway, and blame the leftovers. I said nothing. I am saying nothing now.

The note is **133 characters** long, inside the competition gate of 1–200
characters, a single line, no trailing newline.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes the note to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`). `main.py` uses only the Python standard library and
validates the entry against the gate (1–200 characters, single line,
non-whitespace) before writing it.
